# OASIS UBL 2.1 schemas (vendored)

`maindoc/UBL-Invoice-2.1.xsd` and `common/*.xsd` from the OASIS UBL 2.1 OASIS Standard
package, unmodified, used to validate incoming e-invoices offline (docs/plan-phase1-ubl.md).

Morocco has not published its own e-invoice specification (checked 2026-11-17). Where the
Moroccan identifiers go is our assumption, in config/ubl_ma.yaml.
